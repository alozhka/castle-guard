# План первой играбельной версии Castle Guard

Игрок запускает игру из главного меню, проходит пять уровней подряд и может вернуться в меню. На каждом уровне нужно пройти по всем стенам ровно один раз. Можно отменить последний ход или начать уровень заново. Внешний вид опирается на [референсы](references/). Монеты, подсказки, сохранение прогресса и генерация уровней остаются за рамками этой версии.

## Шаги

Пути указаны от корня репозитория. Новые файлы помечены словом «создать». Для новых ресурсов Unity сохранить сгенерированные файлы `.meta`.

### 1. Собрать главное меню

**Что сделать.** Создать портретную сцену с названием, изображением стража и кнопкой Play по [макету меню](references/Main%20menu.png). Использовать макет как образец композиции. Если отдельного изображения стража пока нет, поставить временное.

**Критерии приёмки.** В Game View при размере 390×844 заголовок, изображение и кнопка видны целиком. Play реагирует на нажатие.

**Файлы.**

- Создать `Assets/Scenes/MainMenu.unity`.
- При наличии отдельного изображения импортировать его в `Assets/Art/UI/`.

### 2. Связать меню и игровую сцену

**Что сделать.** Добавить обе сцены в список сцен сборки. Поставить `MainMenu` первой. Подключить Play к открытию `Level`, а кнопку выхода на поле — к возврату в `MainMenu`.

**Критерии приёмки.** Сборка стартует в меню. Play открывает игровую сцену. Выход возвращает в меню, и Play снова работает.

**Файлы.**

- Создать `Assets/Scripts/GameNavigation.cs`.
- Изменить `Assets/Scenes/MainMenu.unity`.
- Изменить `Assets/Scenes/Level.unity`.
- Изменить список сцен в `ProjectSettings/EditorBuildSettings.asset` либо в используемом Build Profile.

### 3. Собрать квадрат из данных уровня

**Что сделать.** Описать уровень данными: идентификаторы и позиции башен, пары башен для стен, стартовая башня. Сделать prefab из текущей стены. При загрузке поля создавать башни и стены из prefab, назначать буквы и связывать концы стен. Заменить демонстрационную пару башен в сцене этим полем.

**Критерии приёмки.** После Play видны четыре башни и ровно четыре стены: A–B, B–C, C–D, D–A. Башня A выделена как текущая. Стены соединяют нужные башни и используют существующий пунктир.

**Файлы.**

- Создать `Assets/Scripts/LevelDefinition.cs`.
- Создать `Assets/Scripts/LevelController.cs`.
- Создать `Assets/Levels/Level01.asset`.
- Создать `Assets/Prefabs/Wall.prefab`.
- Изменить `Assets/Scenes/Level.unity`.
- Изменить `Assets/Scripts/TowerView.cs`.
- Изменить `Assets/Scripts/WallView.cs`.

### 4. Реализовать движение по стенам

**Что сделать.** Хранить в обычном C# текущую башню, множество пройденных стен и историю ходов. Передавать в эту логику идентификатор башни, на которую нажал игрок. После допустимого хода обновлять выделение башни и рисовать рыжую линию поверх пройденной стены по [примеру маршрута](references/Level%205%20completed%20example.png). Победа наступает, когда пройдены все стены.

**Критерии приёмки.** Клик или тап по соседней башне через свободную стену перемещает стража. Клик по несоседней башне и попытка пройти по использованной стене оставляют состояние прежним. Маршрут A → B → C → D → A завершает уровень после четвёртого хода.

**Файлы.**

- Создать `Assets/Scripts/LevelRun.cs`.
- Изменить `Assets/Scripts/LevelController.cs`.
- Изменить `Assets/Scripts/TowerView.cs`.
- Изменить `Assets/Scripts/WallView.cs`.
- Изменить `Assets/Prefabs/Wall.prefab`.

### 5. Добавить отмену хода и перезапуск

**Что сделать.** Подключить кнопки «Шаг назад» и «Заново» на игровом экране. При отмене вернуть стража в предыдущую башню и освободить последнюю пройденную стену. При перезапуске восстановить стартовое состояние.

**Критерии приёмки.** После A → B → C отмена возвращает стража в B и позволяет снова пройти B–C. В начале уровня «Шаг назад» недоступен. «Заново» возвращает стража в A и очищает все отметки прохода.

**Файлы.**

- Изменить `Assets/Scenes/Level.unity`.
- Изменить `Assets/Scripts/LevelRun.cs`.
- Изменить `Assets/Scripts/LevelController.cs`.

### 6. Собрать окно победы

**Что сделать.** Добавить панель поверх игрового поля по [макету победы](references/Win%20popup.png). Подключить «В меню» и «Дальше». Пока следующий уровень недоступен, скрывать «Дальше». Строку награды добавить вместе с экономикой.

**Критерии приёмки.** Панель появляется после последнего допустимого хода и блокирует нажатия на поле. «В меню» возвращает на стартовый экран. «Дальше» видно только при наличии следующего уровня.

**Файлы.**

- Изменить `Assets/Scenes/Level.unity`.
- Изменить `Assets/Scripts/LevelController.cs`.
- Изменить `Assets/Scripts/GameNavigation.cs`.

### 7. Добавить уровни 2–5

**Что сделать.** Добавить четыре набора данных и упорядочить их после первого уровня. По кнопке «Дальше» загружать следующее поле в той же сцене и начинать новую попытку. Для домика использовать квадрат A–B–C–D с крышей D–E–C. Для уровня 4 использовать два треугольника с общей башней A.

| Уровень | Стены | Старт | Маршрут для проверки |
| --- | --- | --- | --- |
| 2. Квадрат с диагональю | AB, BC, CD, DA, AC | A | A → B → C → D → A → C |
| 3. Домик | AB, BC, CD, DA, DE, EC | D | D → A → B → C → D → E → C |
| 4. Два треугольника | AB, BC, CA, AD, DE, EA | A | A → B → C → A → D → E → A |
| 5. Поле из референса | AB, BC, CA, AD, DE, EC, CD | A | A → B → C → A → D → E → C → D |

**Критерии приёмки.** Каждый маршрут из таблицы проходит все стены своего уровня ровно один раз. «Дальше» открывает уровни по порядку и сбрасывает историю. После пятого уровня доступен возврат в меню.

**Файлы.**

- Создать `Assets/Levels/Level02.asset`.
- Создать `Assets/Levels/Level03.asset`.
- Создать `Assets/Levels/Level04.asset`.
- Создать `Assets/Levels/Level05.asset`.
- Изменить `Assets/Scenes/Level.unity`.
- Изменить `Assets/Scripts/LevelController.cs`.

### 8. Проверить полный игровой цикл

**Что сделать.** Пройти все пять уровней из меню, проверить неверные ходы, отмену, перезапуск и возврат в меню. Проверить портретный экран в Game View и, при наличии целевого телефона, в сборке.

**Критерии приёмки.** Все пять уровней проходимы, переходы и кнопки работают, окно победы перекрывает поле, интерфейс помещается на экране. После возврата в меню Play начинает новую игру с первого уровня. В Console нет ошибок во время прохождения.

**Файлы.**

- Новые файлы для проверки не нужны.
- Исправления вносить в сцены, данные или скрипты, где найдена проблема.
