# Игра “Castle guard”

## Концепция

В сети есть примеры похожих математических задач с обходом фигуры по таким же правилам. Новизна игры заключается в том,
что она обыгрывается в концепции замка, Игрок не просто решает очередную задачу, но и управляет полноценным стражем, от
которого зависит безопасность замка.

### Упрощение до hyper casual

Игроку не требуется изучать сложные правила. Основная механика объясняется одной короткой инструкцией и демонстрируется
визуально.

### Использовать маленькое количество вершин и рёбер с постепенным увеличением

1. Игрок видит фигуру из вершин и рёбер
2. Одна вершина выбирается как стартовая
3. Игрок выбирает следующую соседнюю вершину
4. Маркер перемещается по выбранному ребру
5. Пройденное ребро визуально отмечается и больше не может быть использовано
6. Игрок продолжает движение по ещё не пройденным рёбрам
7. Игрок может отменить свой ход и вернуться к предыдущей вершине
8. При успешном прохождении открывается следующий уровень

### Способ генерации одного уровня

Игровая фигура представляется в виде графа, состоящего из вершин и рёбер.

Для каждого уровня задаются:
- количество вершин;
- количество рёбер;
- связи между вершинами;
- стартовая вершина.

Главное ограничение при генерации: каждое ребро должно быть пройдено ровно один раз.

#### Первые уровни

- 4-5 вершин
- небольшое количество рёбер
- простая структура
- небольшое количество вариантов маршрута

Уровень 1:
- Квадрат. Игрок просто обводит его по кругу.
- Понимание того, что нужно сделать

Уровень 2:
- Квадрат с одной диагональю.
- Понимание, что нельзя проходить по одному и тому же ребру дважды

Уровень 3:
- Домик из 6 ребер
- Понимание, что нельзя проходить по одному и тому же ребру дважды

Остальные уровни: генерируются алгоритмом

Для увеличения сложности постепенно:
- увеличивается количество вершин
- увеличивается количество рёбер
- появляется больше пересечений и разветвлений
- увеличивается количество возможных вариантов движения
- становится сложнее определить, какое ребро необходимо выбрать следующим

### Паттерны mobile gestures

Основной жест: handling tap gestures. Tap используется для выбора следующей вершины.

Игрок нажимает на соседнюю вершину, после чего маркер перемещается по соединяющему её ребру.

### Если 3D или мета
Игра 2D
Монеты даются за:
- Завершение уровня
- Сбор монет при обходе замка

Решение до 30 секунд приносит x1.5 монет за уровень (использование подсказок сбрасывает множитель).
Решение без возврата маршрута приносит x2 монет за уровень (использование подсказок сбрасывает множитель)

За монетки можно купить подсказки:
- Следующее направление движения (стрелкой подсвечивает ребро по которому нужно пройтись следующим шагом)
- Показать весь маршрут

## Механика

### Цели:
- Обойти все башни и переходы замка, при этом обойдя каждый переход только один раз

### Задачи:
- Перемещать маркер по ребрам графа, отмечая пройденный путь.

### Ресурсы:
- Время
- Монеты
- Объект (граф: башни-вершины, проходы-рёбра),
- Действие (выбор следующей вершины - тап)

### Правила:
- Замок представлен в виде графа:
  - Башня (вершина) - имеет степень (количество проходов)
  - Проход (ребро) - соединяет две башни
- Башни расположены на экране так, чтобы линии проходов не пересекались
- Игрок начинает в изначально известной стартовой башне
- Игрок может перейти только в соседнюю башню по существующему проходу
- По каждому проходу можно пройти только один раз
- Посещать башню можно сколько угодно раз
- Уровень считается пройденным, когда все проходы посещены
- Игрок имеет возможность отменить ход (вернуться к предыдущей башне)
- Игрок имеет возможность воспользоваться подсказкой, если у него достаточно монет. Она подсвечивает следующую башню
- За прохождение уровня без подсказок по времени не более 30 секунд, игроку дает 1,5х бонус монет
- За прохождение уровня без подсказок, без ошибок и менее, чем за 30 секунд, игроку дает удвоенный бонус монет
- Количество получаемых монет рассчитывается по правилам математического округления

### Процедуры:
- Чтобы начать или закончить игру - выбрать в меню соответствующий пункт
- Выбрать следующую башню (тап по соседней вершине или драг до соседней вершины)
- Отменить ход (кнопка Назад)
- Начать заново (кнопка Реверс)
- Использовать подсказку - нажать соответствующую кнопку подсказки
  - Показать следующее направление движения
- Переход на следующий уровень (кнопка Дальше)

### Вызовы/Развиваемые скиллы:
- Просчитывание решения наперёд / стратегическое мышление и планирование
- Анализ всей ситуации
- Концентрация
